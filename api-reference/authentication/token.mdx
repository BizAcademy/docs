---
title: "Obtenir un jeton d'application"
description: "Échangez les identifiants d'une application contre un jeton Bearer RS256."
openapi: "openapi.json POST /auth/application/token"
---

Utilisez uniquement cet endpoint depuis votre serveur. Le jeton généré avec le `client_id` et le `client_secret` a une durée de validité de **24 heures (`86400` secondes)** et doit être réutilisé jusqu'à son expiration. Après 24 heures, vous devez générer un nouveau jeton.

<RequestExample>
```bash cURL
curl --request POST \
  --url https://account.bizconnectpay.com/api/v1/auth/application/token \
  --header 'Accept: application/json' \
  --header 'Content-Type: application/json' \
  --data '{
    "client_id": "BCP_live_8R4K2M7N",
    "client_secret": "bcp_secret_replace_me"
  }'
```

```json Payload
{
  "client_id": "BCP_live_8R4K2M7N",
  "client_secret": "bcp_secret_replace_me"
}
```
</RequestExample>
