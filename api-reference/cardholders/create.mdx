---
title: "Créer un porteur de carte"
description: "Enregistrez un client avant d'émettre sa première carte virtuelle."
openapi: "openapi.json POST /cardholders"
---

Le porteur doit avoir au moins 18 ans. `business_name` est obligatoire lorsque `is_business` vaut `true`.

<RequestExample>
```bash cURL
curl --request POST \
  --url https://api.bizconnectpay.com/api/v1/cardholders \
  --header 'Authorization: Bearer <access_token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "first_name": "Amina",
    "last_name": "Ndiaye",
    "email": "amina@example.com",
    "country_code": "237",
    "contact": "690000000",
    "dob": "1995-04-18",
    "billing_name": "Amina Ndiaye",
    "is_business": false,
    "billing_address": "Bonamoussadi",
    "billing_city": "Douala",
    "billing_country": "CM",
    "billing_state": "Littoral",
    "billing_postal_code": "237",
    "id_number": "ID-CM-908172"
  }'
```
