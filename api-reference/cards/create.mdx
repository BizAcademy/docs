---
title: "Émettre une carte virtuelle"
description: "Émettez une carte USD et débitez les frais dans la devise du portefeuille."
openapi: "openapi.json POST /cards"
---

`idempotency_key` identifie durablement l'émission. Réutilisez la même valeur lors d'une nouvelle tentative.

<RequestExample>
```bash cURL
curl --request POST \
  --url https://api.bizconnectpay.com/api/v1/cards \
  --header 'Authorization: Bearer <access_token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "customer_id": "f1bdad5d-bb31-410d-869c-44a28e876ded",
    "wallet_id": "4e969910-8f06-4cd2-b92c-01765472e0e9",
    "idempotency_key": "card-issuance-2026-001",
    "debit_currency": "XAF",
    "initial_balance": "10.00",
    "category": "PERSONAL",
    "grade": "STANDARD"
  }'
```

```json Payload
{
  "customer_id": "f1bdad5d-bb31-410d-869c-44a28e876ded",

}
```
</RequestExample>
