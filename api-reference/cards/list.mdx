---
title: "Lister les cartes virtuelles"
description: "Parcourez les cartes virtuelles de l'application sans exposer leurs données sensibles."
openapi: "openapi.json GET /cards"
---

Cette liste ne contient ni PAN, ni CVV, ni code PIN. Utilisez le détail sensible uniquement au moment où l'utilisateur en a besoin.

<RequestExample>
```bash cURL
curl --request GET \
  --url 'https://api.bizconnectpay.com/api/v1/cards?per_page=25' \
  --header 'Accept: application/json' \
  --header 'Authorization: Bearer <access_token>'
```
</RequestExample>
