---
title: "Gérer une carte virtuelle"
description: "Alimentez, retirez, activez, désactivez ou terminez une carte."
openapi: "openapi.json POST /cards/{virtualCard}/operations"
---

Le champ `amount` est obligatoire uniquement pour `topup` et `withdraw`. Pour `withdraw`, fournissez aussi une `idempotency_key` unique et réutilisez-la sans modification si vous relancez la même requête. Le retrait entraîne les frais configurés par l'administrateur (valeur initiale : 2 USD), convertis dans la devise du portefeuille au taux actif. La réservation des frais est capturée si le fournisseur confirme le succès; en cas d'échec définitif, elle est libérée.

<RequestExample>
```bash cURL
curl --request POST \
  --url https://api.bizconnectpay.com/api/v1/cards/3b2c08e5-d8f2-4886-aad1-88977d455ff8/operations \
  --header 'Authorization: Bearer <access_token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "action": "topup",
    "amount": "25.00"
  }'
```

```json Payload
{
  "action": "topup",
  "amount": "25.00"
}
```
</RequestExample>

<ResponseExample>
```json 200 OK
{
  "success": true,
  "data": {
    "card_id": "38537f3f-3948-43af-fd9d-08df17dfe646",
    "action": "topup",
    "amount": "25.00",
    "currency": "USD",
    "balance": "27.00",
    "status": "successful"
  },
  "meta": {
    "correlation_id": "f9c35025-8a46-4238-982c-f4076c65ca47"
  }
}
```
</ResponseExample>

Exemple de retrait idempotent :

```json
{
  "action": "withdraw",
  "amount": "25.00",
  "idempotency_key": "card-withdrawal-2026-001"
}
```
