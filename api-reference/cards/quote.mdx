---
title: "Obtenir un devis d'émission"
description: "Calculez les frais et le débit du portefeuille avant d'émettre une carte."
openapi: "openapi.json GET /cards/quote"
---

Le taux de change et les frais sont configurés par BizConnectPay. Demandez un nouveau devis avant chaque émission.

<RequestExample>
```bash cURL
curl --request GET \
  --url 'https://api.bizconnectpay.com/api/v1/cards/quote?debit_currency=XAF' \
  --header 'Accept: application/json' \
  --header 'Authorization: Bearer <access_token>'
```
</RequestExample>
