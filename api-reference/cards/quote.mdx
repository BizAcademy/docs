---
title: "Obtenir un devis d'émission"
description: "Calculez les frais et le débit du portefeuille avant d'émettre une carte."
openapi: "openapi.json GET /cards/quote"
---

Le devis sélectionne côté serveur un portefeuille actif du compte marchand disposant d'un solde disponible suffisant. Vous pouvez fournir `debit_currency` comme préférence; ce paramètre est facultatif et ne garantit pas le choix de cette devise si le portefeuille correspondant est insuffisamment approvisionné.

Le montant affiché est calculé avec le tarif configuré pour le marchand, puis converti depuis USD avec le taux de référence configuré (`1 USD = 690 XAF`) et le taux de change actif entre XAF et la devise du portefeuille. Le serveur applique la précision de la devise. Les frais et taux effectifs sont ceux retournés dans le devis.

<RequestExample>
```bash cURL
curl --request GET \
  --url 'https://api.bizconnectpay.com/api/v1/cards/quote' \
  --header 'Accept: application/json' \
  --header 'Authorization: Bearer <access_token>'
```
</RequestExample>

Pour privilégier une autre devise, par exemple CDF, passez `?debit_currency=CDF`. Le serveur utilise le taux XAF→CDF actif (ou l'inverse du taux CDF→XAF s'il n'existe pas de taux direct), choisit un portefeuille actif suffisamment approvisionné et renvoie sa devise et le montant arrondi. Le devis ne réserve pas les fonds; l'émission contrôle à nouveau le solde.
