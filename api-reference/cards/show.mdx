---
title: "Consulter une carte virtuelle"
description: "Récupérez les données à jour et les transactions d'une carte."
openapi: "openapi.json GET /cards/{virtualCard}"
---

<Warning>
  Cette réponse peut contenir le PAN, le CVV et le code PIN. Ne la journalisez pas, ne la mettez pas en cache et ne la conservez pas dans votre base de données.
</Warning>

<RequestExample>
```bash cURL
curl --request GET \
  --url https://api.bizconnectpay.com/api/v1/cards/3b2c08e5-d8f2-4886-aad1-88977d455ff8 \
  --header 'Accept: application/json' \
  --header 'Authorization: Bearer <access_token>'
```
</RequestExample>
