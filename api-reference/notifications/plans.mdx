---
title: "Consulter les forfaits de notification"
description: "Consultez les forfaits d'abonnement disponibles (BASIC, PRO, ENTERPRISE), leurs canaux autorisés et leurs quotas quotidiens."
openapi: "openapi.json GET /notifications/plans"
---

Les forfaits contrôlent les canaux autorisés et les quotas journaliers pour l'ensemble des envois de notifications de votre entreprise :
- **BASIC** : SMS et EMAIL (50 notifications/jour max, 0 WhatsApp).
- **PRO** : SMS, EMAIL et WHATSAPP (500 notifications/jour max, dont 100 WhatsApp).
- **ENTERPRISE** : SMS, EMAIL et WHATSAPP (10 000 notifications/jour max, dont 500 WhatsApp, file prioritaire).

<RequestExample>
```bash cURL
curl --request GET \
  --url https://api.bizconnectpay.com/api/v1/notifications/plans \
  --header 'Accept: application/json'
```
</RequestExample>
