---
title: "Consulter l'état d'une notification"
description: "Suivez le statut d'acheminement et de livraison d'un message envoyé. Scope requis : notifications.read."
openapi: "openapi.json GET /notifications/messages/{id}"
---

Statuts possibles :
- `queued` : Message en attente de traitement.
- `sent` : Message transmis avec succès au destinataire ou à la passerelle Baileys.
- `delivered` : Accusé de distribution confirmé.
- `failed` : Échec de livraison (raison précisée dans la réponse).
- `opted_out` : Envoi bloqué car le destinataire a envoyé `STOP`.

<RequestExample>
```bash cURL
curl --request GET \
  --url https://api.bizconnectpay.com/api/v1/notifications/messages/b304c0ec-6949-4171-8bc9-57ef9a9870be \
  --header 'Authorization: Bearer <application_access_token>' \
  --header 'Accept: application/json'
```
</RequestExample>
