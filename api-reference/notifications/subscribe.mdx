---
title: "Souscrire à un forfait"
description: "Souscrivez à un forfait de notifications avec débit sécurisé sur le solde d'un portefeuille entreprise."
openapi: "openapi.json POST /notifications/subscribe"
---

Seuls les comptes **Entreprise** (`BUSINESS`) approuvés peuvent souscrire à un forfait. Les frais du forfait sont réservés puis capturés directement sur le portefeuille spécifié.

<RequestExample>
```bash cURL
curl --request POST \
  --url https://api.bizconnectpay.com/api/v1/notifications/subscribe \
  --header 'Authorization: Bearer <access_token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "plan": "PRO",
    "wallet_id": "4e969910-8f06-4cd2-b92c-01765472e0e9",
    "auto_renew": true
  }'
```
</RequestExample>
