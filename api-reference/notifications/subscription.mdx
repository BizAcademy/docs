title: "Consulter l'abonnement et la consommation"
description: "Vérifiez le forfait actif de votre compte, la date d'échéance, le renouvellement automatique et la consommation quotidienne en cours."
openapi: "openapi.json GET /notifications/subscription"
---

Retourne l'état de l'abonnement en cours ainsi que les compteurs d'envois réalisés sur la journée par canal :

<RequestExample>
```bash cURL
curl --request GET \
  --url https://api.bizconnectpay.com/api/v1/notifications/subscription \
  --header 'Authorization: Bearer <access_token>' \
  --header 'Accept: application/json'
```
</RequestExample>
