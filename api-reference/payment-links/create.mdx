---
title: "Créer un lien de paiement"
description: "Créez une page de paiement hébergée par BizConnectPay."
openapi: "openapi.json POST /payment-links"
---

Cet endpoint est réservé aux comptes `BUSINESS` dont le KYB est approuvé.

<RequestExample>
```bash cURL
curl --request POST \
  --url https://api.bizconnectpay.com/api/v1/payment-links \
  --header 'Authorization: Bearer <access_token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "amount": "12500",
    "currency": "XAF",
    "description": "Facture octobre",
    "max_uses": 1,
    "expires_at": "2026-10-31T23:59:59Z"
  }'
```

```json Payload
{
  "amount": "12500",
  "currency": "XAF",
  "description": "Facture octobre",
  "max_uses": 1,
  "expires_at": "2026-10-31T23:59:59Z"
}
```
</RequestExample>
