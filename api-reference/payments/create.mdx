---
title: "Créer un paiement"
description: "Initiez une collecte ou un dépôt avec une clé d'idempotence."
openapi: "openapi.json POST /payments"
---

Envoyez une clé `Idempotency-Key` stable pour la même opération métier. Une nouvelle clé crée une nouvelle opération.

Consultez `GET /services` avant l'intégration. Si la méthode choisie indique `otp_required: true`, recueillez le code à usage unique et envoyez-le dans `payer.otp_code`. La valeur peut être omise pour les méthodes qui ne l'exigent pas. Les codes ne sont transmis qu'au fournisseur dont la configuration les attend.

Une méthode telle que Wave peut renvoyer `redirect_url` dans la réponse. Redirigez le payeur vers cette URL pour qu'il termine l'autorisation. La réponse inclut `provider_reference` quand le fournisseur a déjà accepté la demande; cette référence est utile pour rapprocher le paiement.

<RequestExample>
```bash cURL
curl --request POST \
  --url https://api.bizconnectpay.com/api/v1/payments \
  --header 'Authorization: Bearer <access_token>' \
  --header 'Content-Type: application/json' \
  --header 'Idempotency-Key: order-9481-collection' \
  --data '{
    "amount": "15000",
    "currency": "XAF",
    "country": "CM",
    "operation": "COLLECTION",
    "payment_method": "mtn_momo",
    "payer": {
      "phone_number": "+237671234567",
      "lang": "fr"
    },
    "description": "Paiement commande 9481",
    "metadata": {
      "client_reference": "CMD-2026-9481"
    }
  }'
```
