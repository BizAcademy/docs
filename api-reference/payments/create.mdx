---

Envoyez une clé `Idempotency-Key` stable pour la même opération métier. Une nouvelle clé crée une nouvelle opération.

Consultez `GET /services` avant l'intégration. Si la méthode choisie indique `otp_required: true`, recueillez le code à usage unique et envoyez-le dans `payer.otp_code`. La valeur peut être omise pour les méthodes qui ne l'exigent pas. Les codes ne sont transmis qu'au fournisseur dont la configuration les attend.

Certaines méthodes peuvent renvoyer `redirect_url` dans la réponse. Redirigez le payeur vers cette URL pour qu'il termine l'autorisation. La réponse inclut `provider_reference` lorsque l'itinéraire de paiement a déjà accepté la demande; cette référence est utile pour rapprocher le paiement.

Pour un paiement crypto, consultez [Paiements et décaissements crypto](./crypto). Le catalogue vous indique les méthodes crypto disponibles et les cryptomonnaies acceptées.

## Djamo avec AfribaPAY

Pour une collecte Djamo, utilisez `payment_method: "djamo"` dans les pays et devises où `GET /services` retourne cette méthode. AfribaPAY documente Djamo en Côte d’Ivoire et au Sénégal en XOF. La disponibilité réelle peut évoluer : vérifiez toujours le catalogue avant de proposer la méthode.

Le payeur doit ouvrir le lien retourné et scanner le QR code avec l’application Djamo. Après acceptation de la demande, BizConnectPay expose le lien du fournisseur sous `redirect_url`. Présentez ce lien au payeur et laissez-le ouvrir la page; ne considérez pas la demande comme payée à ce stade.

```json Exemple de collecte Djamo
{
  "amount": "500",
  "currency": "XOF",
  "country": "CI",
  "operation": "COLLECTION",
  "payment_method": "djamo",
  "payer": {
    "phone_number": "+2250700000000",
    "lang": "fr"
  },
  "description": "Commande 4821"
}
```

Le statut final reste à vérifier avec `GET /payment-intents/{id}` ou avec les webhooks BizConnectPay. Utilisez `provider_reference` pour le rapprochement. Le lien Djamo ne remplace pas la vérification d’un statut `COMPLETED`.

<RequestExample>
```bash cURL
curl --request POST \
  --url https://api.bizconnectpay.com/api/v1/payments \
  --header 'Authorization: Bearer <access_token>' \
  --header 'Content-Type: application/json' \
  --header 'Idempotency-Key: order-9481-collection' \
  --data '{
    "amount": "15000",
    "currency": "XAF",
    "country": "CM",
    "operation": "COLLECTION",
    "payment_method": "mtn_momo",
    "payer": {
      "phone_number": "+237671234567",
      "lang": "fr"
    },
    "description": "Paiement commande 9481",
    "metadata": {
      "client_reference": "CMD-2026-9481"
    }
  }'
```
