---
title: "Créer un payout"
description: "Envoyez des fonds depuis un portefeuille vers un bénéficiaire."
openapi: "openapi.json POST /payouts"
---

La clé `Idempotency-Key` empêche un double décaissement lors d'une nouvelle tentative.

<RequestExample>
```bash cURL
curl --request POST \
  --url https://api.bizconnectpay.com/api/v1/payouts \
  --header 'Authorization: Bearer <access_token>' \
  --header 'Content-Type: application/json' \
  --header 'Idempotency-Key: payout-5012' \
  --data '{
    "wallet_id": "4e969910-8f06-4cd2-b92c-01765472e0e9",
    "amount": "25000",
    "currency": "XOF",
    "country": "CI",
    "payment_method": "orange_money",
    "destination": "+2250701020304",
    "metadata": {"client_reference": "PAYOUT-5012"}
  }'
```

