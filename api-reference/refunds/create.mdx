---
title: "Créer un remboursement"
description: "Remboursez tout ou partie d'une transaction éligible."
openapi: "openapi.json POST /refunds"
---

<RequestExample>
```bash cURL
curl --request POST \
  --url https://api.bizconnectpay.com/api/v1/refunds \
  --header 'Authorization: Bearer <access_token>' \
  --header 'Content-Type: application/json' \
  --header 'Idempotency-Key: refund-cmd-9481' \
  --data '{
    "transaction_reference": "BCP-TXN-01JAC92Y",
    "wallet_id": "4e969910-8f06-4cd2-b92c-01765472e0e9",
    "amount": "5000",
    "reason": "Article retourné"
  }'
```
