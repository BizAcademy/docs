---
title: "Lister les services disponibles"
description: "Récupérez les pays, devises, opérations et moyens de paiement disponibles."
openapi: "openapi.json GET /services"
---

Le catalogue dépend de l'environnement de l'application et de la disponibilité des fournisseurs.

<RequestExample>
```bash cURL
curl --request GET \
  --url https://api.bizconnectpay.com/api/v1/services \
  --header 'Accept: application/json' \
  --header 'Authorization: Bearer <access_token>'
```
</RequestExample>
