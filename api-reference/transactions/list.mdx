---
title: "Lister les transactions"
description: "Filtrez et parcourez les transactions du compte authentifié."
openapi: "openapi.json GET /transactions"
---

Les filtres sont facultatifs. Utilisez `per_page` pour limiter la taille de la réponse.

<RequestExample>
```bash cURL
curl --request GET \
  --url 'https://api.bizconnectpay.com/api/v1/transactions?status=COMPLETED&currency=XAF&per_page=25' \
  --header 'Accept: application/json' \
  --header 'Authorization: Bearer <access_token>'
```
</RequestExample>
