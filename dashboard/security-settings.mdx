## Authentification à deux facteurs (2FA)

BizConnectPay propose plusieurs canaux de validation en deux étapes pour protéger vos opérations sensibles (connexion, retraits, désactivation) :

<CardGroup cols={2}>
  <Card title="Email" icon="envelope">
    Réception d'un code OTP à 6 chiffres sur votre adresse email enregistrée.
  </Card>
  <Card title="WhatsApp" icon="message">
    Réception instantanée de votre code OTP directement sur votre WhatsApp connecté.
  </Card>
  <Card title="SMS" icon="mobile">
    Code OTP expédié par SMS sur votre numéro mobile vérifié.
  </Card>
  <Card title="Application TOTP" icon="qrcode">
    Génération continue de codes par Google Authenticator, Microsoft Authenticator ou Authy.
  </Card>
</CardGroup>

### Activation de la double authentification

1. Dans **Paramètres** > **Sécurité**, choisissez votre canal de réception favori (ex: WhatsApp ou Email).
2. Cliquez sur **Activer la double authentification**.
3. Saisissez le code de validation reçu pour confirmer votre possession du canal.
4. Notez précieusement la liste de vos **8 codes de récupération d'urgence**. Ils vous permettront d'accéder à votre compte si vous perdez l'accès à votre téléphone.

### Désactivation sécurisée

Si vous souhaitez désactiver la double authentification, cliquez sur **Désactiver la 2FA**. Une boîte de dialogue de confirmation vous invite à valider votre choix. Votre session reste active sans risque de déconnexion inattendue.

## Simulateur de frais interactif

Le tableau de bord intègre un simulateur dynamique pour anticiper vos coûts financiers :

- **Sélection de l'opération** :
  - *Collecte de fonds* (Paiement reçu)
  - *Décaissement* (Virement sortant vers Mobile Money ou Banque)
- **Choix de la devise** : XAF, XOF, USD, EUR.
- **Répartition des frais** :
  - *Frais à la charge du marchand* : Déduits automatiquement du montant net crédité.
  - *Frais à la charge du client payeur* : Ajoutés au montant réglé sur la page de paiement.
- **Résultat instantané** : Affichage en direct du montant brut, du pourcentage de commission appliqué, des frais fixes éventuels et du montant net final.
