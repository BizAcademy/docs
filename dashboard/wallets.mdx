BizConnectPay intègre une architecture de portefeuilles multi-devises permettant de gérer vos fonds dans plusieurs devises régionales et internationales sans ouvrir de multiples comptes bancaires.

---

## Devises prises en charge

- **XAF (Franc CFA CEMAC)** : Devise principale pour le Cameroun, Gabon, Congo, Tchad, RCA, Guinée Équatoriale.
- **XOF (Franc CFA UEMOA)** : Devise pour la Côte d'Ivoire, Sénégal, Bénin, Togo, Burkina Faso, Mali, etc.
- **USD (Dollar Américain)** : Pour vos opérations internationales et le provisionnement des cartes virtuelles.
- **EUR (Euro)** : Pour les règlements de factures et transactions transfrontalières.

---

## Alimenter votre solde (Dépôt)

Depuis l'onglet **Portefeuilles**, cliquez sur **Recharger le solde** :

1. **Sélectionnez le portefeuille cible** (ex: Portefeuille XAF).
2. **Indiquez le montant** à approvisionner.
3. **Choisissez le moyen de paiement** :
   - **MTN Mobile Money** (push USSD instantané).
   - **Orange Money** (code OTP ou push USSD).
   - **Carte bancaire Visa / Mastercard** (saisie 3D Secure sécurisée).
4. Dès validation de l'opération sur votre téléphone ou par votre banque, votre solde disponible est crédité en temps réel.

---

## Effectuer un retrait (Décaissement / Payout)

Vous pouvez à tout moment transférer vos revenus disponibles vers votre compte Mobile Money personnel ou le compte bancaire de votre société :

1. Cliquez sur **Effectuer un retrait**.
2. Sélectionnez le mode de versement :
   - **Mobile Money** : Saisissez le numéro de téléphone bénéficiaire et le nom associé. Le versement est exécuté en moins d'une minute.
   - **Virement bancaire (IBAN / RIB)** : Renseignez le nom de la banque, le code guichet et le numéro de compte. Les fonds sont crédités selon les délais interbancaires standards (généralement 24h ouvrées).
3. Entrez le montant souhaité en respectant votre solde disponible et les frais applicables affichés en toute transparence.
4. Confirmez la transaction à l'aide de votre code de sécurité 2FA.

<Tip>
  Les frais de décaissement sont calculés et déduits automatiquement au moment de la demande. Vous visualisez toujours le montant net exact qui sera crédité sur le compte destinataire.
</Tip>
