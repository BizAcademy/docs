BizConnectPay expose deux surfaces HTTPS distinctes :

<CardGroup cols={2}>
  <Card title="Authentification" icon="key" href="/authentication">
    `https://account.bizconnectpay.com/api/v1` échange votre Client ID et votre secret contre un jeton Bearer RS256.
  </Card>
  <Card title="API de paiement" icon="server" href="/quickstart">
    `https://api.bizconnectpay.com/api/v1` traite les services, collectes, payouts, transactions et cartes virtuelles.
  </Card>
</CardGroup>

<Warning>
  Le `client_secret` doit rester exclusivement sur votre serveur. Ne le placez jamais dans une application web ou mobile distribuée aux utilisateurs.
</Warning>

## Parcours d'intégration

<Steps>
  <Step title="Créer une application">
    Depuis le tableau de bord marchand, créez une application, choisissez `SANDBOX` ou `LIVE`, puis attribuez uniquement les scopes nécessaires.
  </Step>
  <Step title="Générer des identifiants">
    Copiez le `client_id` et le `client_secret`. Le secret n'est affiché qu'une fois.
  </Step>
  <Step title="Obtenir un jeton">
    Appelez l'endpoint d'authentification sur `account.bizconnectpay.com`. Réutilisez le jeton jusqu'à son expiration.
  </Step>
  <Step title="Appeler l'API">
    Envoyez le jeton Bearer à `api.bizconnectpay.com` et utilisez une clé d'idempotence unique pour chaque écriture financière.
  </Step>
</Steps>
