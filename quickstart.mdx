## 1. Obtenir un jeton d'application

```bash
curl --request POST \
  --url https://account.bizconnectpay.com/api/v1/auth/application/token \
  --header 'Accept: application/json' \
  --header 'Content-Type: application/json' \
  --data '{
    "client_id": "BCP_your_client_id",
    "client_secret": "your_application_secret"
  }'
```

```json
{
  "success": true,
  "data": {
    "access_token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJSUzI1NiJ9...",
    "expires_in": 86400,
    "token_type": "Bearer",
    "environment": "SANDBOX",
    "scope": "payments.read payments.write transactions.read"
  },
  "meta": {
    "correlation_id": "3f551f5a-b809-4e0e-9dd7-52efaf784633"
  }
}
```

## 2. Lire les services disponibles

```bash
curl --request GET \
  --url https://api.bizconnectpay.com/api/v1/services \
  --header 'Authorization: Bearer <access_token>' \
  --header 'Accept: application/json'
```

La réponse contient uniquement les combinaisons pays, devise, opération, méthode de paiement et fournisseur activées par l'administrateur.

## 3. Initier une collecte

```bash
curl --request POST \
  --url https://api.bizconnectpay.com/api/v1/payments \
  --header 'Authorization: Bearer <access_token>' \
  --header 'Content-Type: application/json' \
  --header 'Idempotency-Key: order-9481-collection' \
  --data '{
    "amount": "15000",
    "currency": "XAF",
    "country": "CM",
    "operation": "COLLECTION",
    "payment_method": "mtn_momo",
    "payer": {
      "phone_number": "+237671234567",
      "lang": "fr"
    },
    "description": "Paiement commande 9481",
    "metadata": {
      "client_reference": "CMD-2026-9481"
    }
  }'
```

<Info>
  En `SANDBOX`, BizConnectPay conserve le même format de requête et de réponse que `LIVE`, mais ne transmet pas l'opération financière au fournisseur réel.
</Info>
